### ✈️ Airline Delay Analysis Dashboard

An interactive **Power BI dashboard** designed to analyze airline performance, flight delays, cancellations, and operational trends. The dashboard provides a clear view of which airlines and routes experience the most delays and helps identify patterns affecting overall flight performance.

**🛠️ Tools Used:**
Power BI • Power Query • DAX • Data Cleaning • Data Visualization

**📊 Key Analysis:**

* Analyzed overall flight delays and cancellations
* Compared airline performance based on delays and average flight time
* Identified the best and worst-performing airlines
* Analyzed delay distribution and cancellation rates
* Examined flight trends and operational patterns
* Created interactive visuals and KPIs for quick performance evaluation

**💡 Business Insights:**
The dashboard helps airlines and stakeholders identify major delay patterns, compare operational performance, and understand areas where flight operations can be improved to reduce delays and cancellations.
